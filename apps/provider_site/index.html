GreenTokens Provider

Connect your computers into one. One button.

Install it on each computer, share a code, press the power button. Disconnect any time.

Download for Windows Download for Mac

Windows 10 or 11 · macOS 11 or newer (Apple silicon and Intel) · Free · Version 0.1.0 (preview)

Three steps

  1. Install on each computer. Windows: if it says "Windows protected your PC", click More info → Run anyway. Mac: drag the app to Applications, then right-click → Open → Open the first time.
  2. Computer 1: Start a group and copy the code. Other computers: Join a group and paste it.
  3. Press the power button. The first time, setup takes a few minutes. Windows asks once to allow the app on your private network; a Mac may ask to find devices on your local network: choose Allow.
This is a preview. Groups really connect computers on your local network, protected by the code. Only join groups run by people you trust: the leader can run programs on connected computers. On Windows, your network must be set to Private. Mixing Windows and Mac in one group is untested. It never connects by itself, and closing the app disconnects.
To remove it: Windows Settings → Apps → Installed apps → GreenTokens Provider → Uninstall; Mac: drag the app from Applications to the Trash. · Release notes
