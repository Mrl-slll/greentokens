GreenTokens Provider

Connect your computers into one. One button.

Install it on each computer, share a code, press the power button. Disconnect any time.

This download is for Windows PCs. Open this page on a Windows 10 or 11 computer.

Download for Windows

Windows 10 or 11 · Free · Version 0.1.0 (preview)

Three steps

  1. Install on each computer. If Windows says "Windows protected your PC", click More info, then Run anyway.
  2. Computer 1: Start a group and copy the code. Other computers: Join a group and paste it.
  3. Press the power button. The first time, setup takes a few minutes and Windows asks once to allow the app on your private network.
This is a preview. Groups really connect computers on your local network, protected by the code. Only join groups run by people you trust: the leader can run programs on connected computers. Your network must be set to Private in Windows. It never connects by itself, and closing the app disconnects.
To remove it: Windows Settings → Apps → Installed apps → GreenTokens Provider → Uninstall. · Release notes
